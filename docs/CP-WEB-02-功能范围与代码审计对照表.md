## 1 先对齐一个事实：中英双语已经做完了

你说「暂时不必开发完整英文站」，这一点需要澄清：

**双语不是「待开发」，而是「已完成」。** 当前 `/` 是中文站、`/en/` 是英文站，前台所有页面（含文章详情、收银台、个人中心、问答）都已完成双语，导航与站点设置也支持 `label_en` / `value_en`。

所以处理方式不是「砍掉」，而是**冻结在现状**：

| 做法 | 说明 |
|---|---|
| 代码与路由保留 | 撤掉要改一堆代码，纯损失，没有任何收益 |
| 不再投入增量 | 不写英文内容、不做英文 SEO、不接国际支付 |
| 不进验收范围 | 后续每个任务只验中文站，英文站不阻塞交付 |

其余冻结项（多币种、全球 SEO、多区域部署、多创作者、多服务商、任务大厅）**本来就没做**，不需要额外清理。
